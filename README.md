# The WASD Keyboard

An interactive 3D keyboard experience built with Next.js, React Three Fiber, Three.js, Tailwind CSS, and shadcn/ui.

Press **W**, **A**, **S**, or **D** to animate the matching key, hear its mechanical sound, and see its baked material darken as it moves down.

## Local development

Install dependencies with pnpm install, then start the project with pnpm dev.

## Production build

Run pnpm build, followed by pnpm start.
